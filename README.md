## 续费不涨价是真的，但有两个例外条件

是真的。官网 FAQ 原话：这些 VPS 特价套餐是 lifetime recurring（终身循环价格），只要你决定继续用，续费就一直是同一个价。你现在花 $35.99 买的 2 GB 套餐，明年、后年的账单都是 $35.99，不随官网调价变动。在“首年低价、续费翻倍”盛行的 VPS 行业里，这条政策的稀缺性就是它的价值。

续费操作本身不难：系统会在到期前约两周自动生成续费账单发到注册邮箱；也可以在客户区进入 VPS 详情页，点左侧 Actions 里的"Generate Renewal Invoice"手动生成账单，付款后立即生效。付款方式方面，官网确认支持 AMEX、Discover、VISA 等主流信用卡，第三方资料显示还支持 PayPal 和支付宝。

但续费同价不是无条件生效，两个例外情况在多数推广文章里被略过了：

1. **服务不能断档**。到期不续导致服务暂停后再重新激活，可能不再按原活动价计费，相当于按当时现行价格重新下单。想锁价，就保持连续续费。
2. **升级会重置价格基准**。中途升级到更高档套餐要补差价，但升级后续费按新套餐价格算，原活动价不再保留。预期一年内就要升级的话，第一次就买对档位更划算。
